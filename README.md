# h1saki-tools

ゲーム配信・動画制作・日常の作業効率化に使う自作ツールを公開するリポジトリです。

OBS Studio関連を含め、実際に使って便利だったスクリプトや小さなツールを順次追加します。

> [!IMPORTANT]
> 現在は [OBS設定バックアップ](obs/backup/README.md)、[OBSマイク設定](obs/microphone/README.md)、[OBS環境移行・復元支援](obs/restore/README.md)（Windows・試験版）を公開しています。
> 試験版のため、利用前に各ツールのREADMEで対応環境と既知の制限を確認してください。

## このリポジトリについて

- ツールは用途ごとのフォルダに分けて公開します。
- 各ツールの導入方法、必要環境、変更内容は、それぞれのREADMEに記載します。
- 公開前または開発途中のツールは、予告なく仕様を変更する場合があります。
- 不具合報告や提案はGitHub Issuesで受け付けます。ただし、個別環境への導入代行や動作保証は行いません。

## 主なカテゴリー

| フォルダ | 内容 | 状態 |
|---|---|---|
| [`obs/`](obs/README.md) | OBS Studio・配信環境を補助するツール | 試験公開中 |

OBS以外のツールは、公開時にカテゴリーと案内を追加します。

## ディレクトリ構成

```text
カテゴリー名/
  README.md    カテゴリーの案内
  scripts/     スクリプト本体
  examples/    秘密情報を含まない設定例
  docs/        導入・利用手順
```

各ツールを使う前に、そのフォルダ内のREADMEを確認してください。

## 基本的な使い方

1. 目的に合うカテゴリーを開きます。
2. 対象ツールのREADMEで、対応OS・必要ソフト・動作確認済みバージョンを確認します。
3. 既存の設定やデータをバックアップします。
4. スクリプトの内容と変更対象を確認してから実行します。
5. 問題が起きた場合は、各ツールに記載された復元手順を実行します。

## 安全上の注意

- 実行前にスクリプトと変更内容を確認してください。
- ツールが変更する設定やデータは、実行前にバックアップしてください。
- 配信キー、APIキー、トークン、パスワード、個人情報を含むバックアップ・設定・ログは、公開または共有しないでください。
- スクリプトは各自の環境と責任で利用してください。
