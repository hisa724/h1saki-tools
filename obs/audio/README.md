# OBS 音声一括設定

配信で「叫び声は聞こえるのに、考えながらのボソボソ喋りが聞こえない」状態を解消するスクリプトです。
**マイク**と**デスクトップ音声**の両方をまとめて設定します。

## 設定は `obs/settings.ini` で（推奨）

スクリプトの引数を覚えなくても、**`obs/settings.ini` を書き換えるだけ**で値を変えられます。

1. `obs/settings.example.ini` を同じフォルダに **`settings.ini`** という名前でコピー
2. `[audio]` の値を書き換える
3. `configure-audio_ver.0.1.cmd` をダブルクリック

```ini
[audio]
GainDb=18.5
ExpanderThreshold=-45
DuckRatio=10
```

- 優先順位: **引数 > settings.ini > スクリプトの既定値**（引数で指定したものだけ引数が勝つ）
- `settings.ini` は個人の環境を含むので Git には入りません（`.gitignore` 済み）

## 使い方

OBS を**完全に終了**してから、`configure-audio_ver.0.1.cmd` をダブルクリックしてください。
実行前にシーンコレクションのJSONを `../backup/` へ日付付きで退避します。

まず中身だけ確認したい場合:

```powershell
.\configure-audio_ver.0.1.ps1 -WhatIf
```

## 何をするか

### マイク

| 順 | フィルター | 設定 |
|----|-----------|------|
| 1 | ノイズ抑制 | RNNoise |
| 2 | **ゲイン** | +18.5 dB |
| 3 | エキスパンダー | しきい値 **-45 dB** / 比率 2 |
| 4 | 3バンドイコライザー | 低 -4 / 中 0 / 高 0 |
| 5 | コンプレッサー | 比率 3 / しきい値 -20 dB / 出力 +3 dB |
| 6 | リミッター | -3 dB |

**ゲインをエキスパンダーより前に置くのが要点です。** 後ろに置くと、エキスパンダーが増幅前の
小さい信号を見てしまい、普通に喋っているだけで減衰対象になります。しきい値が -20 dB のような
高い値になっていると、叫んだときだけ通って小声が削られます。

### デスクトップ音声

| 順 | フィルター | 設定 |
|----|-----------|------|
| 1 | **ダッキング**（サイドチェーン圧縮） | 比率 10:1 / しきい値 -35 dB / アタック 5 ms / リリース 200 ms / サイドチェーン: マイク |
| 2 | リミッター | -3 dB |

**マイクに声が入っている間だけゲーム音が自動で下がります。** 声が埋もれる問題に最も効きます。

## 不要なフィルタを外す（スクリプトの編集は不要）

`settings.ini` の `[audio]` で、要らないものを `false` にします。

```ini
[audio]
NoiseSuppress=true
Expander=false      ; 小声が削られるなら、まず OFF を試す
Equalizer=false     ; 好みで
Compressor=true
Limiter=true
Ducking=true        ; false にするとデスクトップ音声はリミッターだけになる
```

- ゲインは常に入ります（値は `GainDb`）
- 実行時に「適用する設定」として **実際に入るフィルタの並び**が表示されるので、押す前に確認できます
- 既に OBS に入っているフィルタは**全部置き換え**られます（手で足したものは残りません）。残したいものがある場合は、下の「スクリプトを直接編集する」で足してください

### スクリプトを直接編集する（ini に無いものを足す・値を変える）

`configure-audio_ver.0.1.ps1` の次の2か所が、フィルタの中身です。

| 場所 | 内容 |
|---|---|
| `# マイク:` から始まるブロック（`$micFilters`） | マイクのフィルタ。**並び順＝OBSでの順番** |
| `# デスクトップ音声:` から始まるブロック（`$desktopFilters`） | デスクトップ音声のフィルタ |

1行が1フィルタです。例えばコンプレッサーの比率を 4 にしたいなら、その行の `ratio = 3` を `ratio = 4` に変えるだけです。
フィルタを足すときは、同じ形の行を増やします（`New-Filter '表示名' 'OBSの内部ID' @{ 設定 }`）。
内部IDは OBS の既存フィルタを一度手で作り、シーンコレクションのJSON（`%APPDATA%\obs-studio\basic\scenes\`）で `"id"` を見れば分かります。

編集後は `-WhatIf` で並びを確認してから実行してください。

```powershell
.\configure-audio_ver.0.1.ps1 -WhatIf
```

### `microphone/` との違い

`obs/microphone/configure-microphone_ver.0.1` はマイクだけを設定する旧版です。
**音声は `audio/` を使ってください**（マイク＋デスクトップ音声、settings.ini 対応、フィルタの ON/OFF あり）。

## 主なオプション

```powershell
.\configure-audio_ver.0.1.ps1 -DuckRatio 6 -DuckThreshold -30
```

| パラメーター / ini キー | 既定 | 説明 |
|-------------|------|------|
| `GainDb` | 18.5 | マイクに足すゲイン |
| `ExpanderThreshold` | -45 | 上げるほど小声が削られる |
| `CompressorThreshold` | -20 | マイクのコンプレッサー |
| `DuckThreshold` | -35 | マイクがこれを超えるとゲーム音が下がる |
| `DuckRatio` | 10 | 大きいほどゲーム音が深く下がる |
| `MicName` | マイク | マイク音源の名前 |
| `DesktopName` | デスクトップ音声 | デスクトップ音声の名前 |
| `-ConfigRoot` | `%APPDATA%\obs-studio` | OBS設定フォルダ（検証用） |

## 適用後の確認

1. OBS を起動する
2. ミキサーの歯車 → フィルタ で、マイクとデスクトップ音声に入っているか見る
3. 少し喋って、ゲーム音が下がることを確認する
4. 喋っているときメーターが **-12 dB 前後**、ピークが **-6 dB** を超えないよう入力音量を調整する

## 元に戻す

`../backup/scenes-before-audio-<日時>.json` を
`%APPDATA%\obs-studio\basic\scenes\<コレクション名>.json` に上書きしてください。
**OBS は終了しておくこと。**

## 音声トラックを分けて録るのを推奨します

設定 → 出力 → 録画 → **音声トラック** で複数にチェックを入れると、

| トラック | 中身 |
|---------|------|
| 1 | ミックス |
| 2 | マイクのみ |
| 3 | ゲーム音のみ |

に分かれて記録されます。1本に混ざったままだと、**後から編集でマイクだけ上げることができません。**
