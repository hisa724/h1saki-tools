# OBS tools

OBS Studio向けツールの配置場所です。

> [!WARNING]
> **設定バックアップを実行する前に、OBS Studioを必ず終了してください。**
> OBS起動中は設定ファイルの整合性を守るため、バックアップを作成せず停止します。

## 公開中のツール

| ツール | 内容 | 状態 |
|---|---|---|
| [OBS設定バックアップ](backup/README.md) | Windows版OBSの設定を日時付きZIPへ保存（実行前にOBSの終了が必須） | 試験版 |

## 構成

```text
obs/
  backup/      OBS設定のバックアップツール
  機能名/      今後追加する機能ごとのツールとREADME
```

各機能の対応環境、変更内容、実行方法、既知の制限は、それぞれのフォルダにあるREADMEで確認してください。

## バックアップファイルの取り扱い

OBSのバックアップZIPや実際の設定ファイルには、次の情報が含まれる可能性があります。

- 配信キー、APIキー、トークン、パスワード
- OBS WebSocketの認証情報
- ブラウザCookieやログイン状態
- マイクなどのデバイスID
- Windowsのユーザー名や個人環境の保存パス

バックアップZIPや実設定は、GitHub、Issue、チャット、公開クラウドへアップロードしないでください。

不具合を報告する場合は、バックアップそのものを添付せず、エラーメッセージからユーザー名、保存パス、認証情報を伏せたうえで投稿してください。

## サンプル設定

このリポジトリで設定例を公開する場合は、認証情報や個人環境の値をダミーへ置き換えます。サンプルの値をそのまま実環境の認証情報として使用しないでください。
