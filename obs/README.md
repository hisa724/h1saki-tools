# OBS tools

OBS Studio向けツールの配置場所です。

## 公開中のツール

| ツール | 内容 | 状態 |
|---|---|---|
| [OBS設定バックアップ](docs/backup-settings.md) | Windows版OBSの設定を日時付きZIPへ保存 | 試験版 |

## 構成

```text
obs/
  scripts/     実行するスクリプト
  examples/    サンプル設定
  docs/        導入・使い方・復元手順
```

## 公開時の必須事項

各ツールには、同じフォルダまたは `docs/` に次の情報を用意します。

1. 対応OSと前提ソフトウェア
2. 変更されるOBS設定
3. インストール・実行方法
4. アンインストールまたは復元方法
5. 動作確認済みのOBSバージョン
6. 既知の制限事項

## 秘密情報

次の情報を含む実ファイルは公開しません。

- 配信キー、APIキー、トークン、パスワード
- OBS WebSocketの認証情報
- 本名、メールアドレス、ローカルのユーザーフォルダ名
- 個人環境を特定できる絶対パス

設定例が必要な場合は、値をダミーに置き換えて `examples/` に配置します。
