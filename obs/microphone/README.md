# OBSマイク設定（Windows・動作検証中）

ゲーム実況向けのマイク基準設定を、現在のOBSシーンコレクションへ適用するツールです。

> [!CAUTION]
> `ver.0.1` は作成済みですが、現在は動作検証中です。実際の声を使ったテスト録音が完了するまでは完成版として扱いません。

## 適用する設定

1. ノイズ抑制: RNNoise
2. エキスパンダー: 2:1、しきい値 -40 dB
3. 3バンドEQ: 低域 -4 dB、中域 0 dB、高域 0 dB
4. ゲイン: +3 dB
5. コンプレッサー: 3:1、しきい値 -18 dB、出力 +3 dB
6. リミッター: -4 dB
7. 音声: 48kHz・ステレオ

現在の `+16 dB` ゲインとコンプレッサー出力 `+9 dB` による過剰な増幅を抑えるための安全な基準値です。部屋の騒音、マイク機種、口元との距離によって最終調整が必要です。

## 安全対策

- OBS起動中は処理を停止します。
- 現在のシーンJSONと `basic.ini` を日付付きで退避します。
- 適用に失敗した場合は変更前の設定へ戻します。
- マイクデバイス自体は変更せず、現在選択されているデバイスを維持します。
- 配信キーや配信設定には触れません。
- `-WhatIf` で変更前に確認できます。
- 隔離テスト用の `-TestMode` は、Windowsの一時フォルダ外を変更できません。

## 事前確認

```powershell
.\configure-microphone_ver.0.1.ps1 -WhatIf
```

## 適用

```powershell
.\configure-microphone_ver.0.1.ps1
```

値を調整する場合：

```powershell
.\configure-microphone_ver.0.1.ps1 -GainDb 3 -ExpanderThreshold -40 -CompressorThreshold -18
```

## 適用後の確認

無言10秒、普通の声20秒、大きな声5秒を録音し、次を確認してください。

- 普通の声: -18～-12 dB
- 大きな声: -10～-6 dB
- 最大値: -3 dB以下（AAC変換後のピーク上昇を考慮し、リミッター自体は -4 dB）
- 無言時: 可能なら -50 dB以下
- 語尾が切れない
- 息やキーボード音が不自然に持ち上がらない
- コンプレッサーによる音量の揺れが目立たない
